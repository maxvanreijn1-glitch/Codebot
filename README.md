# Codebot - AI Code Analysis Platform

An intelligent code analysis platform powered by Claude (Anthropic) that provides GitHub-style diff views and actionable suggestions.

## Features

- **AI-Powered Analysis**: Claude analyses your code and provides intelligent suggestions
- **GitHub-style Diffs**: View proposed changes with a beautiful diff viewer
- **Multi-language Support**: TypeScript, Python, Go, Java, Ruby, PHP, and more
- **Secure File Uploads**: Upload entire codebases for analysis
- **Usage Tiers**: Free, Pro, and Premium plans with Stripe payments
- **JWT Authentication**: Secure token-based authentication
- **Rate Limiting**: Protects against abuse
- **Local Repository Management**: Register and watch local repos
- **Pull Request Workflow**: Create, review, and merge AI-generated PRs
- **Copilot-style Suggestions**: Real-time inline code suggestions

```
│       ├── routes/      # API routes (auth, claude, payments, …)

└── package.json         # Root build & start scripts
```

## Deploying to Render

### Prerequisites

- A [Render](https://render.com) account
- An [Anthropic](https://console.anthropic.com) API key
- A [Stripe](https://stripe.com) account (optional, for payments)

### One-Click Deploy

1. Fork or push this repository to GitHub.
2. In the Render dashboard click **New → Blueprint** and connect the repository.
3. Render will read `render.yaml` and provision:
   - A **Web Service** (`codebot-server`) running the combined Node.js app
   - A managed **PostgreSQL** database (`codebot-db`)
4. Set the required environment variables (see table below) in the Render dashboard.
5. Trigger a deploy – the server will automatically run the database schema on startup.

### Required Environment Variables

| Variable | Description | Auto-generated? |
|---|---|---|
| `DATABASE_URL` | PostgreSQL connection string | ✅ Injected by Render |
| `JWT_SECRET` | Secret for signing JWTs (min 32 chars) | ✅ Generated by Render |
| `ANTHROPIC_API_KEY` | Claude API key from Anthropic console | ❌ Set manually |
| `STRIPE_SECRET_KEY` | Stripe secret key | ❌ Set manually |
| `STRIPE_WEBHOOK_SECRET` | Stripe webhook signing secret | ❌ Set manually |
| `CORS_ORIGIN` | Comma-separated allowed origins, e.g. `https://codebot.onrender.com` | ❌ Set manually |
| `NODE_ENV` | Set to `production` | ✅ Set in render.yaml |
| `PORT` | Server port | ✅ Injected by Render |

### Optional Environment Variables

| Variable | Default | Description |
|---|---|---|
| `LOCAL_REPOS_PATH` | `/tmp/local-repos` | Directory for local repository storage |
| `PR_REVIEW_REQUIRED` | `true` | Require review before merging PRs |
| `COMMAND_TIMEOUT` | `30000` | CLI command timeout in milliseconds |
| `SUGGESTION_DEBOUNCE` | `1000` | Copilot suggestion debounce in milliseconds |

## Local Development

### Prerequisites

- Node.js 18+
- PostgreSQL 15+ (or Docker)

### 1. Clone and install dependencies

```bash
# Install server dependencies
cd server && npm install

# Install client dependencies
cd ../client && npm install
```

### 2. Configure environment

```bash
# Copy the example env file and fill in your values
cp server/.env.example server/.env
```

### 3. Start PostgreSQL (via Docker Compose)

```bash
docker-compose up -d
```

### 4. Run in development

```bash
# Terminal 1 – backend (auto-restarts on file change)
cd server && npm run dev

# Terminal 2 – frontend (Vite HMR)
cd client && npm run dev
```

The app is available at:
- **Frontend**: http://localhost:5173
- **Backend API**: http://localhost:5000

The server will automatically create all required database tables on first startup.

## Troubleshooting

| Symptom | Likely cause | Fix |
|---|---|---|
| `Missing required environment variables` at startup | `DATABASE_URL`, `JWT_SECRET`, or `ANTHROPIC_API_KEY` not set | Add the missing variable in Render dashboard |
| `ECONNREFUSED` connecting to PostgreSQL | Database not started / wrong `DATABASE_URL` | Confirm the DB service is healthy in Render |
| Stripe webhooks not working | Wrong `STRIPE_WEBHOOK_SECRET` or endpoint URL | Re-verify the webhook secret in Stripe dashboard |
| CORS errors in browser | `CORS_ORIGIN` doesn't include your frontend URL | Update `CORS_ORIGIN` env var |
| 404 on page refresh (production) | SPA fallback not working | Ensure `NODE_ENV=production` is set |
